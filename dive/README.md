# Dive
Dive is a 2048-like blending additive and multiplicative number theory,
invented by [Allen Knutson](https://www.google.com/+AllenKnutson) and others
and implemented first by [TheMoreYouKnow](https://github.com/themoreyouknow).
This version is based on [Alex Fink's implementation](https://alexfink.github.io/dive/).

# Changes/additions:

-Color options for the webpage

-A chart showing recent scores

-A seed quest list

-A speedrun timer

-Fixed mobile retry button
